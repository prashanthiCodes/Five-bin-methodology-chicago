# Data sources, attribution, and sharing review

This project has not been pushed to GitHub or published. Check this file and the data-quality report before making a public repository.

## Dataset inventory

| Data | Source and use | Sharing status / caveat |
| --- | --- | --- |
| Tract indicator fields | User-provided local ACS workbooks, reduced to aggregate tract fields in `data/source/acs_tract_inputs_2014.csv`, `...2019.csv`, and `...2024.csv` | The fields appear to be aggregate ACS estimates, not person-level records. The source workbook did not include a dataset-level citation, table IDs, codebook, or license. Confirm provenance and sharing rights before a public GitHub release. |
| Home-value proxy | U.S. Census Bureau ACS Summary File, table B25077, median value for owner-occupied housing units, for 2014, 2019, and 2024 | U.S. Census public statistical data; cite Census Bureau ACS. The measure is not a sale price. Source download URLs are recorded in `scripts/prepare_inputs.py`. |
| Tract polygons | U.S. Census Bureau TIGER/Line 2010 Cook County tracts and TIGER/Line 2020 Illinois tracts | Census TIGER/Line documentation states U.S. Government work is not copyright protected in the United States and asks users to cite the Census Bureau. The files carry an accuracy disclaimer and are statistical boundaries, not legal land descriptions. A City of Chicago 2020 tract export was checked but omitted because it lacked three GEOIDs present in the supplied 2024 tract input. |
| Community-area house-value workbook | Existing local project workbook | Excluded: it is community-area rather than tract level, and its source/license provenance could not be established. |

The Census Bureau’s [ACS data release page](https://www.census.gov/programs-surveys/acs/news/data-releases/2024/release.html) documents the 2024 five-year release. Its [2014 Summary File page](https://www.census.gov/programs-surveys/acs/data/summary-file/sequence-based/2014.html), [2019 Summary File page](https://www.census.gov/programs-surveys/acs/data/summary-file.2019.html), and [2024 Summary File page](https://www.census.gov/programs-surveys/acs/data/summary-file/2024.html) describe the source files used for B25077. Census [TIGER/Line documentation](https://www.census.gov/geographies/mapping-files/time-series/geo/tiger-line-file.html) describes the tract boundary products. Its [TIGER/Line legal disclaimer and citation page](https://www2.census.gov/geo/pdfs/maps-data/data/tiger/tgrshp2026/TGRSHP2026_TechDoc_Ch1.pdf) states that government works are not copyright protected in the United States, requests Census attribution, and explains the boundaries are for statistical purposes and carry no accuracy warranty.

The Census Bureau’s [citation policy](https://www.census.gov/about/policies/citation.html) asks analysts who create estimates from disseminated data to cite the Census Bureau as the original source and makes clear that analytic conclusions are the performing party’s responsibility. No additional dataset-specific sharing restriction was stated in the official Summary File and TIGER source documentation reviewed for this project. Retain Census attribution and the TIGER accuracy/statistical-use disclaimer. This project downloaded Summary Files and TIGER/Line files from Census FTP locations rather than using the Census API. The source data here are aggregate tract estimates and geometries; no respondent-level or other microdata are included.

## Required review before external publication

The source XLSX files were available only in the existing local project. Their worksheet data identify tract-level estimates and some variable names, but they do not identify Census table IDs for all 11 non-proxy indicators or document the compiler’s license. The project retains only the aggregate fields needed for this analysis, but the precise workbook provenance and sharing terms remain unverified. Review the source workbook documentation or obtain confirmation of permission before publishing the derived CSVs or classifications to a public repository. Until then, keep this project local/private. No approval has been inferred.

The community-area house-value workbook is not copied into this project or used in its calculations. Census public data and TIGER boundaries do not contain sensitive individual records, but the sharing review for the supplied workbook extracts is still outstanding.
