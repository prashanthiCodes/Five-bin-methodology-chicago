# Chicago tract-level analysis

The docs directory is the local review package for the static GitHub Pages site. Research inputs, scripts, detailed reports, and full house-price classifications remain local and are excluded by .gitignore.

Review docs before publication. House-price workbook values are withheld pending approval to share them. The source workbook metadata for the supplied ACS-derived inputs also needs confirmation. Do not push or enable Pages until those reviews are complete.

For GitHub Pages, select the main branch and docs folder after publication is approved. The site uses relative paths, static JSON, Census tract GeoJSON, and HTTPS Leaflet CDN assets; it does not require local-drive paths or Python at runtime.
